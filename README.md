# Дослідження ймовірностей при киданні двох гральних кубиків за допомогою методу Монте-Карло

У цьому дослідженні було реалізовано статистичне моделювання (метод Монте-Карло) для імітації 1 000 000 кидків двох гральних кубиків. Метою роботи було підрахувати частоту випадіння кожної можливої суми (від 2 до 12) та порівняти отримані результати з теоретичними (аналітичними) розрахунками теорії ймовірностей.

## Фінальні висновки

1. **Ефективність методу Монте-Карло:**  
   Експеримент наочно довів високу точність методу Монте-Карло. При масштабі симуляції в 1 000 000 кидків абсолютна похибка (відхилення експериментальних даних від теорії) для кожної суми **не перевищила 0.06%**, а для найпопулярнішої суми (7) збіглася ідеально до сотих часток відсотка ($16.67\%$).

2. **Закон великих чисел:**  
   Отримані дані є прямим практичним підтвердженням закону великих чисел. Він стверджує, що при збільшенні кількості випадкових випробувань відносна частота подій стає максимально близькою до їхньої справжньої математичної ймовірності.

3. **Характер розподілу ймовірностей:**  
   Таблиця чітко демонструє **симетричний (трикутний) розподіл**:
   * Суми **2** та **12** мають найнижчу ймовірність ($\approx 2.78\%$), оскільки їх можна отримати лише одним єдиним комбінаційним шляхом ($1+1$ та $6+6$ відповідно).
   * Сума **7** є піковою і має найвищу ймовірність ($\approx 16.67\%$), оскільки її можна сформувати найбільшою кількістю комбінацій на гранях кубиків (аж 6 різних варіантів).

4. **Загальний підсумок:**  
   Метод Монте-Карло є незамінним інструментом у випадках, коли аналітичний розрахунок є занадто складним або математично неможливим (наприклад, у криптографії, моделюванні фізичних процесів чи фінансовому аналізі). Комп'ютерна симуляція великої кількості випадкових подій дозволяє отримати результат високої точності без використання складних інтегралів чи комбінаторних формул.
